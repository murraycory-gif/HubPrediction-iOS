HUB Predictions — update on the Windows PC, then test in the browser
====================================================================

FIRST TIME (do this once)
-------------------------
1. Stop the old desk: click the terminal that is running npm run dev, press Ctrl+C.
2. Open Command Prompt.
3. Go to the repo folder (the folder that contains hub-prediction):

   cd /d C:\Users\Cory\Developer\HubPrediction-iOS

4. Kalshi keys stay on this PC only. Do not paste PEM in Safari.
   Next to the repo (same folder as hub-prediction), make a .secrets folder:

   HubPrediction-iOS\.secrets\kalshi_key_id.txt
   HubPrediction-iOS\.secrets\kalshi_key.pem

   Or put KALSHI_KEY_ID and KALSHI_PRIVATE_KEY in hub-prediction\.env.local.

5. Double-click update-desk.bat  (or run the one-liner below).
6. On this PC open Edge or Chrome:  http://localhost:8080
7. Hard-refresh: Ctrl+Shift+R
8. Confirm Live is OFF. P&L should be cash minus deposits (example: $263 − $760 = −$497).
   The lower bets log should list Kalshi fills since the first deposit.

EVERY TIME AFTER I SHIP A CHANGE
--------------------------------
In PowerShell, one line (Ctrl+C the old desk window first):

cd C:\Users\Cory\Developer\HubPrediction-iOS; git fetch origin cursor/desk-pnl-bets-charts-be4f; git checkout -B cursor/desk-pnl-bets-charts-be4f FETCH_HEAD; cd hub-prediction; npm.cmd install; npm.cmd run dev

Then wait until that window prints Local: http://localhost:8080. Open that URL and press Ctrl+Shift+R.
Do not refresh Chrome until that line appears. Refreshing a stopped desk shows "localhost refused to connect".

Already pulled and just want to start without git (fixes refused-to-connect):

   double-click start-desk.bat
