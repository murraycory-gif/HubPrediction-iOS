HUB Predictions — update on the Windows PC, then test in the browser
====================================================================

FIRST TIME (do this once)
-------------------------
1. Stop the old desk: click the terminal that is running npm run dev, press Ctrl+C.
2. Open Command Prompt.
3. Go to the repo folder (the folder that contains hub-prediction):

   cd /d C:\path\to\HubPrediction-iOS

   Use your real path. If you are not sure, in File Explorer open the repo
   folder, click the address bar, copy the path, then:

   cd /d PASTE-THAT-PATH

4. Pull the current desk (host keys + clocks + this updater):

   git fetch origin
   git checkout cursor/host-kalshi-creds-be4f
   git pull origin cursor/host-kalshi-creds-be4f

5. Kalshi keys stay on this PC only. Do not paste PEM in Safari.
   Next to the repo (same folder as hub-prediction), make a .secrets folder:

   HubPrediction-iOS\.secrets\kalshi_key_id.txt
   HubPrediction-iOS\.secrets\kalshi_key.pem

   Or put KALSHI_KEY_ID and KALSHI_PRIVATE_KEY in hub-prediction\.env.local.

6. Double-click update-desk.bat  (or run it from that same Command Prompt).
7. On this PC open Edge or Chrome:  http://localhost:8080
8. Hard-refresh: Ctrl+Shift+R
9. Confirm Live is OFF. If Kalshi answers, cash should not stay as a dash.

EVERY TIME AFTER I SHIP A CHANGE
--------------------------------
In PowerShell, one line (Ctrl+C the old desk window first):

cd C:\Users\Cory\Developer\HubPrediction-iOS; git fetch origin cursor/host-kalshi-creds-be4f; git checkout -B cursor/host-kalshi-creds-be4f origin/cursor/host-kalshi-creds-be4f; cd hub-prediction; npm.cmd install; npm.cmd run dev

Then open the Local URL it prints (http://localhost:8080 or 8081) and press Ctrl+Shift+R.

Already pulled and just want to start without git:

   double-click start-desk.bat
